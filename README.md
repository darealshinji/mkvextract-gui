Simple FLTK based mkvextract GUI for Linux.
mkvinfo and mkvextract have to be in PATH.

To compile together with FLTK run `./build_fltk.sh && make`.
To compile using system-wide FLTK run `make` without building FLTK first.
C++20 or newer is required.

You can create a .mkv file for testing with `./test/mux.sh`
